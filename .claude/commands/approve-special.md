---
description: Approve a pending special price.
---

Run: `npm run price -- approve-special <special-id> --actor=`

Below the floor the command stops. Only pass --below-floor-ok with the approver's stated reason.

Options use --name=value. Add --json for structured output. Show money with its currency and margins as percentages. Drafts go to drafts/ and are never sent from here.
